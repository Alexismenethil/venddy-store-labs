# Venddy Store · Arquitectura de Software

Laboratorio de análisis y arquitectura de una plataforma web multiempresa para negocios de comida.

## Estructura inicial

- `analisis-de-sistema/`: actores, historias de usuario, requisitos, calidad, restricciones y drivers.
- `arquitectura/`: arquitectura inicial y diagramas.

Los documentos se desarrollarán y publicarán por etapas mediante Conventional Commits.
